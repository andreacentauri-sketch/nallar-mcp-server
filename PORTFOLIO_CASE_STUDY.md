# Portfolio Case Study — NALLAR MCP Server

## Problem
Expose trustworthy AI-engineering context to agents without coupling them directly to canonical application internals.

## Solution
A read-only stdio JSON-RPC MCP server with tools, resources, prompts, explicit failures, and package/evidence adapters.

## Engineering highlights
Protocol handshake, discovery surfaces, path confinement, positive/negative tests, evidence discipline, and reproducible packaging.

## Interview angle
Discuss protocol design, agent-tool security boundaries, observability, failure semantics, and how this MCP layer can later connect RAG and multi-agent components.
